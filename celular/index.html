TELEFONO CELULAR

En este apartado se explica qué implica el embalaje de un teléfono celular y por qué debe realizarse de forma especial para proteger la evidencia digital.El embalaje de un teléfono celular consiste en aislar el dispositivo de cualquier señal externa para preservar la información digital contenida en él (mensajes, llamadas, fotos, ubicaciones, aplicaciones, etc.).

¿Por qué se usa bolsa de Faraday o de aluminio? Porque bloquea las señales de radiofrecuencia (llamadas, datos móviles, WiFi, Bluetooth y GPS). Esto impide que el teléfono pueda ser borrado de forma remota, bloqueado, rastreado o modificado desde fuera. Si el dispositivo sigue recibiendo señal, existe el riesgo de que se altere o elimine evidencia digital importante.

⬇

MATERIALES NECESARIOS

Aquí se detallan los elementos necesarios para embalar correctamente un teléfono celular y proteger su información digital.

  • guantes de latex
  • Bolsa de Faraday (o bolsa de aluminio)(del tamaño adecuado)
  • Cinta adhesiva (de evidencia o normal)
  • Tijeras
  • Marcador permanente
  • Cinta adhesiva normal
  • sobre manila
  • Etiqueta de evidencia

PROCEDIMIENTO PASO A PASO

A continuación se describe el paso a paso correcto para embalar un teléfono celular preservando su evidencia digital.

  • Con el uso de guantes, tomar el teléfono celular.
  • Introducirlo dentro de una bolsa de Faraday o de aluminio (esto hace que pierda toda señal).
  • Colocar la bolsa con el teléfono dentro de un sobre de Faraday.
  • Cerrar el sobre y sellarlo con cinta adhesiva.
  • Sellar las esquinas y gran parte del sobre con cinta.
  • Con un marcador permanente, marcar todas las esquinas del sobre (preferentemente también sobre la cinta) para detectar cualquier manipulación.

PRECAUCIONES

En este apartado se indican las medidas necesarias para no alterar ni comprometer la evidencia digital del teléfono.

  • Utilizar siempre guantes desechables.
  • No encender ni manipular el teléfono más de lo necesario.
  • No intentar desbloquear el dispositivo.
  • Aislarlo de señales lo antes posible.
  • No usar bolsas plásticas comunes (no bloquean la señal).
  • Evitar golpes o presión excesiva sobre el equipo.
  • No reutilizar materiales.
  • Realizar un sellado inviolable.
